### 🚀 Featured Projects

#### 🐾 1. **PetPal – Pet Adoption & Pet Care Management Platform**
> *Full-Stack Web Application built with React.js, Node.js, Express.js, PostgreSQL, and Prisma ORM.*

- ⚡ **Key Features:** Full pet adoption workflow with role-based dashboards (Adopters, Shelters, Admins).
- 🔐 **Security:** Secure authentication and authorization via JWT.
- 🏥 **Pet Care Module:** Comprehensive module featuring vaccination tracking, feeding schedules, medical records, and medication management.
- 📐 **Architecture:** Scalable MVC backend architecture with robust input validation and RESTful APIs.

---

#### 🫁 2. **Chest X-Ray Classification for Multi-Disease Detection**
> *Deep Learning Computer Vision System built using PyTorch & Transfer Learning pipelines.*

- 🧠 **Custom Architecture:** Custom 4-block CNN (~3.3M params) trained from scratch, achieving **92% test accuracy** on a 4-class dataset (COVID-19, Normal, Pneumonia, Tuberculosis) outperforming ResNet50 baseline (89%).
- ⚖️ **Data Skew Handling:** 3-phase transfer learning pipeline with class-weighted loss to handle severe class imbalance (~700 TB vs 4000+ Pneumonia samples).
- 🔍 **Explainable AI (XAI):** Integrated **Grad-CAM heatmaps** to visualize and validate clinically relevant activation regions for auditable AI decisions.

---

#### ⏱️ 3. **OS Scheduling Simulator**
> *Real-time visualization tool for CPU Scheduling algorithms built with C++ and React.js.*

- ⚙️ **Algorithms Implemented:** FCFS, SJF, SRTF, Round Robin, LJF, and LRTF.
- 📊 **Real-Time Analytics:** React.js frontend dynamically visualizes Gantt charts, waiting time, turnaround time, and CPU utilization.
- 📈 **Benchmarking:** Evaluates performance trade-offs on identical process sets to convert theoretical OS principles into empirical performance metrics.
